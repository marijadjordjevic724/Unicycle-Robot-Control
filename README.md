# Unicycle-Robot-Control
Trajectory tracking, obstacle avoidance and parking procedure for the unicycle robot. Trajectory tracking is available with 4 different trajectories (more can be added): circle, infinity shaped, triangle and rectangular trajectory. This is enabled with 2 different controllers. Parking procedure with Cartesian regulation scheme.

Controller 1: General control scheme with flatness block

Controller 2: Control with feedback linearization using a point on sagittal axis
